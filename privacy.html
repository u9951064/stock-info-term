Privacy Policy – Josh Tsai Stock Info Backup

Effective date: October 3, 2026

This Privacy Policy explains how Josh Tsai Stock Info Backup ("the app"), operated by Josh Tsai ("we", "the operator"), accesses, uses, stores and shares data, including data obtained through Google APIs.

The app collects no personal information (no name, email address, profile, contacts or other Drive files).

1. Data the app accesses

  • Google account authorization token. When the operator authorizes the app, Google issues an OAuth access token and refresh token. These are stored only in a configuration file on the operator's private server and are used solely to authenticate requests to the Google Drive API.
  • Google Drive files created by the app. Using the drive.file scope, the app can access only the files and folders it has created itself (the stock-info-backup folder and its daily backup subfolders). It cannot see or access any other file in the user's Google Drive.
  • Backup content. The uploaded files are snapshots of the operator's own research database, which contains publicly available Taiwan stock market data (e.g. prices, trading volumes, company revenue reports). They contain no personal information about any individual.

The app does not access the user's name, email address, contacts, Gmail, calendar, photos, or any other Google user data.

2. How the data is used

  • To upload daily backup files to the user's Google Drive.
  • To verify the uploaded files (checksum comparison) after each upload.
  • To delete backup folders previously created by the app so that only the five most recent backups are retained.

Data is not used for advertising, analytics, profiling, machine-learning model training, or any purpose other than providing the backup function described above.

3. Data sharing and disclosure

We do not sell, rent, transfer or share Google user data with any third party. Data is transmitted only between the operator's private server and Google's servers over encrypted HTTPS connections.

4. Storage, retention and security

  • OAuth tokens are stored in a file on the operator's private server, readable only by the operator's account.
  • Backup files are stored in the user's own Google Drive. The app keeps the five most recent daily backups and permanently deletes older backup folders that it created.
  • No copy of Google user data is kept anywhere else.

5. Revoking access and deleting data

You can revoke the app's access at any time at https://myaccount.google.com/permissions. After revocation the app can no longer access Google Drive. Backup files can be deleted by removing the stock-info-backup folder from Google Drive, and the stored token can be removed by deleting the app's configuration on the server.

6. Compliance with the Google API Services User Data Policy

Josh Tsai Stock Info Backup's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. Children's privacy

The app is a personal tool and is not directed at children under 13.

8. Changes to this policy

Changes to this policy will be posted on this page with an updated effective date.
